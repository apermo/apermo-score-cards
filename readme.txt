Gutenberg blocks for card and board game score cards with automatic calculations.

== Description ==

Apermo Score Cards provides Gutenberg blocks for tracking scores during card
and board game sessions, with automatic scoring calculations for darts,
wizard, phase 10, pool billiard, and an evening summary block that totals
results across all games on a page.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/apermo-score-cards/`
2. Activate the plugin through the "Plugins" screen in WordPress
